# 🚀 Cosmic Blaster: Neon Odyssey

![Game Screenshot](assets/images/screenshots/gameplay.png)

An **advanced Python/Pygame space shooter** with stunning visuals, dynamic particles, and intense arcade action. Dodge asteroids, collect power-ups, and climb the leaderboards in this neon-drenched cosmic battleground.

## ✨ Features

- **Next-Gen Particle System**  
  Explosions with trails, starfield parallax, and GPU-optimized rendering
- **Procedural Audio Engine**  
  Dynamically generated sound effects with distortion/chorus effects
- **Neon Cyberpunk UI**  
  Glowing HUD elements, animated buttons, and responsive design
- **Advanced Game Systems**  
  - Weapon power-ups (spread shot, plasma beams)
  - Asteroid physics (fracturing, momentum transfer)
  - Dynamic difficulty scaling
- **Modern Code Architecture**  
  Type hints, singleton patterns, JSON configs, and asset pipelines
